# 石景山区五环以东闲置空间资源动态管理平台

用于领导汇报的 V1.0 静态演示版。平台以地图为入口，展示七类闲置空间资源的筛选、定位、属性查看、变更审核和版本追溯。

## 运行方式

直接打开 `index.html`，或在本目录启动任意静态文件服务器。页面加载后自动播放六个演示步骤，也可通过底部控制条暂停、前进或后退。

## 演示范围

- 七类资源分类与条件筛选
- 点状和面状资源表达
- 街道与卫星底图切换示意
- 规划地块图层开关
- 资源详情、照片区和版本记录
- 新增与修改申请
- 管理员审核中心
- 左右侧栏收起与恢复

## 数据与地图说明

本演示仅使用虚构示例数据，不包含真实业务数据。地图为离线示意底图，代码中保留百度地图接入位置。正式开发时需配置百度地图密钥，并建立规划数据原始坐标、标准空间数据库与 BD-09 展示坐标之间的转换和校核机制。
